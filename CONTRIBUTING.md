# Contributing
Use English for explanations, code comments, and commit messages.

1. Start with [the algorithm template](templates/algorithm.md).
2. Put Python implementations in examples/python/ and tests in tests/.
3. State preconditions, return values, and failure behavior.
4. Explain correctness and complexity, including representation assumptions.
5. Prefer small original examples to copied problem statements or solutions.
6. Run python3 -m unittest discover -s tests -v from the repository root.
7. Check links, update the learning index, and mark only completed roadmap items.

The reference language is Python 3.10+. Keep dependencies limited to the standard library unless a topic needs something else. Additional languages can be added later with equivalent behavior and tests.

# Roadmap
## Available now
- [x] Seven introductory topic guides.
- [x] Binary search, BFS, DFS, inorder traversal, min-heap, and merge sort.
- [x] Tests for boundaries, duplicates, cycles, disconnected vertices, and heap behavior.
- [x] Article template and contribution guidance.

## Core additions
- [ ] Singly linked list, stack, and queue implementations.
- [ ] Hash table collision handling.
- [ ] BST insertion, lookup, and deletion.
- [ ] Bottom-up heap construction and heapsort.
- [ ] Insertion sort, quicksort, and quickselect.
- [ ] Topological sorting and directed-cycle detection.
- [ ] Dijkstra's shortest paths and its nonnegative-weight requirement.
- [ ] Union-find and minimum spanning trees.
- [ ] Two pointers, sliding windows, and prefix sums.
- [ ] Backtracking and dynamic programming exercises.

## Later
Tries; balanced trees; string matching; segment trees; Java versions.

Each new implementation should include a correctness explanation, explicit assumptions, complexity analysis, and tests.
